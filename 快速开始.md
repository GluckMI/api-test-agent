## 📝 自己的第一个测试（复制粘贴即用）

创建文件 `tests/test_hello.yaml`：

```yaml
name: "Hello World API 测试"

steps:
  - name: "测试 GET 请求"
    method: GET
    endpoint: "https://jsonplaceholder.typicode.com/posts/1"
    
    assertions:
      # 检查状态码
      - type: status_code
        expected: 200
      
      # 检查响应时间
      - type: response_time
        max: 5.0
      
      # 检查响应包含特定字段
      - type: contains_key
        key: "title"
        path: "$"
      
      # 检查具体值
      - type: equal
        path: "id"
        expected: 1
```

运行：
```bash
python api_test_agent.py run tests/test_hello.yaml
```

## 🎯 常用场景速查

### GET 请求

```yaml
- name: "获取用户列表"
  method: GET
  endpoint: "https://api.example.com/users"
  
  # 可选：添加查询参数
  params:
    page: 1
    limit: 10
  
  assertions:
    - type: status_code
      expected: 200
```

---

### POST 请求（JSON）

```yaml
- name: "创建用户"
  method: POST
  endpoint: "https://api.example.com/users"
  
  json:
    name: "张三"
    email: "zhang@example.com"
  
  assertions:
    - type: status_code
      expected: 201
    
    - type: contains_key
      key: "id"
      path: "$"
```

---

### POST 请求（表单）

```yaml
- name: "登录"
  method: POST
  endpoint: "https://api.example.com/login"
  
  data:
    username: "admin"
    password: "123456"
  
  headers:
    Content-Type: "application/x-www-form-urlencoded"
```

---

### 带认证的请求

```yaml
- name: "受保护的 API"
  method: GET
  endpoint: "https://api.example.com/profile"
  
  # Bearer Token
  headers:
    Authorization: "Bearer ${ACCESS_TOKEN}"
  
  # 或 Basic Auth
  # auth: ["username", "password"]
```

---

### 变量传递

```yaml
steps:
  # 步骤 1：登录并提取 token
  - name: "登录"
    method: POST
    endpoint: "https://api.example.com/login"
    json:
      username: "test"
      password: "pass"
    
    # 提取响应中的变量
    extract:
      token: "data.token"
      user_id: "data.user.id"
  
  # 步骤 2：使用上一步的变量
  - name: "获取用户详情"
    method: GET
    endpoint: "https://api.example.com/users/${user_id}"
    
    headers:
      Authorization: "Bearer ${token}"
```

## 🔧 断言类型速查表

| 类型 | 用途 | 示例 |
|------|------|------|
| `status_code` | HTTP 状态码 | `expected: 200` |
| `equal` | 值相等 | `path: "id", expected: 1` |
| `contains_key` | 键存在性 | `key: "token"` |
| `type_check` | 数据类型 | `expected_type: str` |
| `length` | 长度检查 | `expected: 10` |
| `response_time` | 响应时间 | `max: 3.0` |
| `regex_match` | 正则匹配 | `pattern: "^\d+$"` |

## 📊 CLI 命令速查

```bash
# 运行单个测试
python api_test_agent.py run test.yaml

# 运行目录下的所有测试
python api_test_agent.py run tests/

# 指定报告格式
python api_test_agent.py run test.yaml --reports html,json

# 指定基础 URL
python api_test_agent.py run test.yaml --base-url https://api.example.com

# 设置超时
python api_test_agent.py run test.yaml --timeout 60

# 查看详细日志
python api_test_agent.py run test.yaml --verbose
```
