### 🔥 高价值 - 低难度（v1.1 优先实现）

#### 1. 更多断言类型

| 新增断言 | 用途 | YAML 示例 |
|---------|------|----------|
| `status_in` | 多个可接受状态码 | `expected: [200, 201]` |
| `not_equal_key` | 键不存在检查 | `key: "error"` |
| `json_path_match` | JSONPath 提取验证 | `path: "$.data[*].id"` |
| `header_contains` | Header 包含检查 | `key: "Content-Type", value: "json"` |
| `is_json` | 响应是有效 JSON | `path: "$"` |
| `response_size` | 响应体大小检查 | `min: 100, max: 10000` |

#### 2. 前置/后置钩子

```yaml
hooks:
  before_all:
    - name: "设置超时"
      method: POST
      endpoint: "/admin/config"
      json: { "timeout": 60 }
  
  after_each:
    - name: "清理临时数据"
      method: DELETE
      endpoint: "/cleanup"

steps:
  # 正常测试步骤...
```

#### 3. 条件跳过

```yaml
steps:
  - name: "获取详情"
    method: GET
    endpoint: "/resource/${item_id}"
    skip: "${API_VERSION} < 2.0"  # 条件不满足时跳过
  
  - name: "高级功能"
    method: GET
    endpoint: "/advanced"
    only_if: "${ENV} == 'staging'"
```

#### 4. 期望结果文件比对

```yaml
steps:
  - name: "完整响应验证"
    method: GET
    endpoint: "/users/1"
    
    expect_file: "tests/expectations/user_1.json"
    # 自动比对响应与期望文件内容
    
    ignore_fields: ["timestamp", "request_id"]  # 忽略动态字段
```

### 🎯 高价值 - 中等难度（v1.2 中期实现）

#### 5. 并发执行

```python
# 方式 1: CLI 命令
python api_test_agent.py run tests/ --workers 4

# 方式 2: Python API
from test_runner import TestRunner

runner = TestRunner(concurrent=True, max_workers=8)
result = runner.execute_directory("tests/", workers=4)
```

**技术要点：**
- 使用 `concurrent.futures.ThreadPoolExecutor`
- 每个 Worker 独立的 APIClient 实例
- 结果聚合和报告合并

#### 6. 数据驱动测试

```yaml
name: "批量用户登录测试"

data_source: "tests/data/users.csv"
# 或
# data_source: "tests/data/users.yaml"
# data_source: "http://test-data.example.com/api/test-data"

steps:
  - name: "登录"
    method: POST
    endpoint: "/login"
    json:
      username: "${username}"
      password: "${password}"
    
    assertions:
      - type: status_code
        expected: 200
```

### 💎 高价值 - 高难度（v2.0 长期规划）

#### 9. GraphQL 支持

```yaml
- name: "GraphQL 查询"
  method: POST
  endpoint: "/graphql"
  json:
    query: |
      query GetUser($id: ID!) {
        user(id: $id) {
          id
          name
          email
        }
      }
    variables:
      id: "123"
  
  assertions:
    - type: contains_key
      key: "data"
      path: "$"
    - type: equal
      path: "data.user.name"
      expected: "张三"
```

#### 10. WebSocket 测试

```yaml
- name: "WebSocket 连接测试"
  type: WEBSOCKET
  endpoint: "ws://echo.example.com"
  
  steps:
    - name: "连接"
      action: connect
      
    - name: "发送消息"
      action: send
      message: '{"type": "ping"}'
      
    - name: "接收响应"
      action: receive
      timeout: 5.0
      expect:
        type: ping
```

#### 11. 数据库验证

```yaml
steps:
  - name: "创建用户"
    method: POST
    endpoint: "/users"
    json: {"name": "测试用户"}
    extract:
      user_id: "id"
  
  - name: "验证数据库记录"
    type: DATABASE
    connection: "${DB_CONNECTION_STRING}"
    query: "SELECT * FROM users WHERE id = ${user_id}"
    
    assertions:
      - type: row_count
        expected: 1
      - type: column_value
        column: "name"
        expected: "测试用户"
```

#### 12. 性能基准测试

```yaml
- name: "压力测试"

  endpoint: "/users"
  
  performance:
    iterations: 1000
    concurrency: 50
    ramp_up: 10  # 秒
    
  thresholds:
    p50: "< 100ms"
    p90: "< 300ms"
    p99: "< 1000ms"
    error_rate: "< 1%"
```

## 八、总结与建议

### ✅ 立即可做的扩展（优先级最高）

1. **增加断言类型** - 投入产出比最高
2. **前后置钩子** - 解决常见痛点
3. **并发执行** - 大幅提升效率
4. **CSV/数据源** - 降低测试成本
